## 문제와 목적

DreamPath와 InnoWorks는 같은 구조로 만든 두 서비스로, 사용자가 AI와 대화하며 결과를 시각화해 볼 수 있습니다. 주식회사 프랜더 인턴 기간 중 2025년 12월 한 달 동안, 기존 Django 풀스택 구조를 Django 백엔드와 React 프론트엔드로 분리하고 다국어 UI를 적용하는 작업을 맡았습니다.

## 내가 맡은 범위

개발팀 3명 중 프론트엔드 개발자는 1명이었고, 두 서비스의 프론트엔드 작업을 모두 맡았습니다.

| 영역 | 직접 맡은 범위 |
|---|---|
| 구조 분리 | Django 풀스택 구조에서 화면을 React 프론트엔드로 분리 |
| 화면/상태 | 로그인 상태, 진행도, 주차 상태 등 서버 데이터를 화면 상태로 연결 |
| 다국어 | 영어, 일본어, 중국어, 스페인어 언어 리소스 구성과 화면 적용 |
| AI 응답 | AI 응답을 서비스 화면 안에서 HTML로 렌더링 |
| 배포 | GitHub Actions 기반 배포 자동화 |

## 결과와 한계

- 두 서비스 모두 영어, 일본어, 중국어, 스페인어 UI로 운영 중입니다.
- 회사 프로젝트라 코드 링크는 제공하지 않습니다.
